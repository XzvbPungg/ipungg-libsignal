# ipungg-libsignal-node

Protokol Signal berbasis Open Whisper Systems untuk Node.js yang aman, bersih, dan kompatibel dengan WhatsApp Web / Baileys (`ipungg-baileys`).

## Instalasi

```bash
npm install ipungg-libsignal-node
```

## Penggunaan dengan Baileys

```json
{
  "dependencies": {
    "libsignal": "npm:ipungg-libsignal-node@^1.0.0"
  }
}
```
